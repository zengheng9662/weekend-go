# WEEKEND GO / 周末出发

> 一个把“周末去哪”的纠结，直接变成可执行计划的 AI 城市探索工具。

## 为什么做它

大学生的周末活动并不少，真正的问题是信息太多、决策成本太高。展览藏在公众号里，市集散落在社交平台，演出和徒步还要重新查天气、距离、预算和同行人数。结果常常是收藏了一大堆，周末还是不知道去哪。

WEEKEND GO 不想再做一个“活动信息瀑布”，而是把重点放在 **从发现到出发** 这一步。

用户只需要告诉系统：今天想怎么过、预算多少、和谁一起。AI 会结合天气、距离、营业时段和个人偏好，直接生成一条可以执行的周末路线，并在天气变化时准备 Plan B。

## 核心体验

### 1. AI 周末生成器
选择心情、预算和同行人数，一键生成半日或一日路线。结果不仅包含“去哪”，还会给出顺序、预算、步行距离、室内外比例与天气备选方案。

### 2. 城市雷达
当用户还想自己逛逛时，再进入活动发现。这里不是把所有活动堆给用户，而是先由 AI 根据天气、距离、预算与兴趣做筛选，再解释“为什么适合你”。活动可直接加入当前路线。

### 3. 同频出发
“找搭子”依附在具体路线、时间和预算上，而不是一个泛社交广场。用户可以加入高度匹配的小队，AI 再综合每个人的时间、预算和兴趣，生成一条小队共同路线。

### 4. 周末足迹
行程结束后，只需留下极轻量的打卡反馈。AI 自动整理成个人周末足迹和可分享攻略，同时把真实体验反哺给下一次推荐。

## 产品特色

WEEKEND GO 的核心不是“推荐更多”，而是 **减少无效选择，让用户真正出发**。

完整路径是：

**偏好输入 → AI 生成路线 → 城市雷达补充探索 → 同路线组队 → 出发打卡 → 攻略沉淀 → 反哺下一次推荐**

这样既覆盖题目要求中的天气、预算、活动推荐、组队、打卡和攻略分享，也形成了一条完整的用户闭环。
