# WEEKEND GO / 周末出发

> 不是告诉你城市里有什么，而是帮你把“周末去哪”的纠结变成一条可以直接出发的路线。

**在线体验：** https://zengheng9662.github.io/weekend-go/

## 产品背景

大学生周末并不缺活动信息，真正缺的是“决定”。展览、市集、演出、徒步、酒吧和餐厅散落在不同平台，还要额外考虑天气、预算、同行人数、距离和时间。信息越多，越容易陷入“收藏很多，最后没出门”。

WEEKEND GO 把 AI 放在决策链路中。用户只需要表达今天的 mood、预算、人数和活动范围，系统就结合天气、距离、时间段与活动属性生成可执行路线，并为天气变化等不确定因素准备 Plan B。

## 核心功能

### 1. 帮我决定
- Mood 多选：看展、徒步、喝酒、看剧/演出、市集、咖啡、运动、海边、桌游、夜游等，也可自定义。
- 预算滑杆 + 快捷金额，控制人均预算上限。
- 同行人数自由调整，并可开启“同频匹配”。
- 深圳区域按行政区 / 新区选择，同时设置出发地。
- 时间段、最大通勤时间、室内外偏好等低频条件折叠在“更多条件”。
- AI 输出一条包含时间、预算、通勤和天气 Plan B 的周末路线，而不是继续堆活动列表。

### 2. 城市雷达
地图点位和活动卡片联动，帮助用户快速理解附近还有什么。AI 匹配度同时解释天气、兴趣、距离和预算等推荐依据。

### 3. 同频出发
不做泛陌生人广场。用户的 mood、预算、时间和活动范围共同组成组队标签，围绕具体路线匹配同行者，并由 AI 找出小队的“最大公约数路线”。

### 4. 周末足迹
“想去收藏”和“已去打卡”放在同一个城市收藏夹。打卡只需要地点、照片和一句感受，真实反馈可以反哺下一次推荐。

### 5. WEEKEND BOT
顶部灵动岛是自然语言入口。用户可以直接说：“两个人，预算 100，想看展但不想走太远。”机器人帮助修改条件、解释推荐，并降低第一次使用的学习成本。

## 产品闭环

**偏好输入 → AI 路线 → 地图补充探索 → 同频组队 → 保存出发 → 打卡收藏 → 真实反馈反哺下一次推荐**
